Frequently Asked Questions


What is CineNexus? +

CineNexus is a movie discovery and streaming-style demo app built to explore and showcase frontend development — think browsing, searching, and viewing details for movies and shows in a Netflix-inspired interface.

Is CineNexus affiliated with Netflix? +

No. CineNexus is an independent personal/portfolio project built for learning purposes. It is not affiliated with, endorsed by, or connected to Netflix or any other streaming service.

Can I actually watch movies on CineNexus? +

No — CineNexus doesn't host or stream any video content. It's a static frontend demo showcasing UI/UX design, not a functional streaming platform.

Where does the movie data come from? +

The poster images used in this demo were sourced from The Movie Database (TMDB) for illustrative purposes. Movie titles, ratings, and descriptions shown are for demonstration only and not pulled from a live database.

Do I need an account to use CineNexus? +

No account system is currently implemented — this is a front-end design demo.

Is my data safe if I sign up? +

There's no real sign-up or data storage in this demo — any forms shown are for UI demonstration only.

Can I request a movie/show to be added? +

Not currently — CineNexus is a static demo with a fixed set of sample titles, not a live catalog.
